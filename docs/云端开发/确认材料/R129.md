## 讲解

- **为什么 mock 有同步方法.** 测试的假登记 (xero_registry) 要在构造时装好摘录与检索. 走同一份读法, 不在测试里重写 JSON 加 PDF 的拼装. async 方法只是转调.
- **文件名的安全.** ACN 只认数字, 姓名只认字母, 空格, 撇号与连字符. 查询串拼进文件名, 不会串出 registry/ 目录. 例如 ACN 写成 "../asic" 时, 不做检查会读到 registry/asic.json.
- **人员检索的 "姓名或出生日期不符".** 文件名就由姓, 名与出生日期拼成; 不符即没有这个文件, 返回 None. 姓名不分大小写 (转大写拼文件名).
- **之后的需求要用的字段.** R290 (ASIC 摘录上传与抽取) 的范围另列了 ABN 与注册地址, 补造目录的 JSON 现在没有这两项, 本条按验收不加, 由 R290 扩展.
