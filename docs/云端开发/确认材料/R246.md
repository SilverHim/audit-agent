## 方案取舍

- **原数据**: 用 R245 的 `tests.tools.cuad_fetch` 取到本工作副本的 data/external/cuad. 它被 gitignore, 不入库. md5 校验通过.
  - 逐页文本由 `pdf_pages` 抽出, 抽取调用同 FileEvidenceStore.pages. 抽取时 PDF 只当数据读.
  - 测试只读入库的 JSON, 不读 data/external.
- **mock 输出的写法**: 人工标注, 不是真实模型的输出, README 写明了. 条款文本是逐页文本的连续片段, 只把换行合并为空格. 跨页的条款 (CUAD-03 的 2.3 交货与 2.7 付款) 接上下一页的部分, 页码记起始页.
  - 印刷页码与条款连在一起的, 原样保留 (如 "Page -5-"). 若删去, 锚点会对不上原页.
- **反编造检查 `fabricated`**: 条款文本的前 60 个字母数字须从声明页开始出现. 为容纳跨页条款, 允许延续到下一页. 正文在第 3 页而声明第 2 页时, 匹配起点落在第 3 页, 照样判为编造. 只在评测里算, 不进正式校验.
- **当事方规范化**:
  - 处理: 去括号里的定义名, 小写, 非字母数字换成空格, 去公司后缀词.
  - 后缀词: 需求列的 inc, corp, llc, ltd, limited, co, pty, 另加 corporation, plc, lp, llp, gmbh, kg. 这样 CUAD-05 的 "Cremer Oleo GmbH & Co KG" 也能对上.
  - 只剩后缀的名称 (规范化后为空) 不算同一方.
- **签订日**: 两位年份 >= 90 补 19yy, 其余补 20yy; 四位年份原样. 含 "[]" 或日期无效 (如 2/30/01) 的为 None.
- **CUAD-05**: 范围要求入库, 本条只入库, 不作用例对象. 供 R247 金标准与以后的评测用.
