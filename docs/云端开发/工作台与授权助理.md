# 审计工作台与授权助理

2026-10-24，根据本地测试反馈实施。新需求优先于此前仅展示程序开始与结束的取舍。

## 工作台

顶部显示五个审计阶段、当前工作状态、真实完成数、模型模式与下一步。左侧显示执行过程、授权方案和对话；右侧集中显示当前待处理事项及决定卡。保留程序目录、审计计划、复核队列和表单入口。

执行过程记录实际发生的规则检查、模型分析、输出校验和结果整理，含并行执行、尝试次数、耗时和结果数量；不展示模型内部思维，不生成虚构百分比。数据作业也记录处理文件和实际数量。事件写入审计留痕，刷新后重放最近事件，可向前加载；重连按游标补齐跨页记录。断线期间保留已显示内容。

系统状态区分正在执行、等待审计决定、等待外部证据、执行异常与已结束。已开始但未形成终态的历史步骤明确标记为未完成，不假装仍在运行。界面采用中英文专业中性表述。

## 授权方案

支持批量标记补充证据无法取得、暂缓或恢复事项、确认可采纳的普通判断、认定完整的错报建议，以及重跑过期程序。方案保存对象编号、版本和指纹、建议结论、授权人及原因。授权时重新检查全部对象；一项变化即整批拒绝。新增事项不自动纳入旧方案。

“请将当前两项待补资料请求全部标记为无法取得”等完整明确指令，可直接授权当前固定批次；数量不符只生成方案。疑问、否定、条件句、引述和笼统的“全部处理”不构成直接授权。其他操作由助理生成方案，经工作台授权按钮执行。阶段审批和报告签发仍通过对应决定卡办理。

批次在一个业务事务内提交，所有决定和回执同时保存；失败整体回滚。重复执行返回原回执，不重复写决定或启动流程。客户端断线后已授权执行继续完成。批量普通决定一次恢复等待节点，检查点故障按已提交记录恢复。完成阶段的补证请求停在原程序等待，无法取得后保留中断并恢复复核入口，不以空输入结束等待；执行阶段及报告闸门按原补证回退机制推进。

## 精简演示

`demo-compact` 为独立合成数据集，与完整 Numbat 使用同一合成客户画像，新建项目仅提供该精简演示，不设数据配置选项；手工新建客户入口保留，原 Numbat 和 Xero 数据保留用于回归验证。

- 期间：2025-07-01 至 2026-06-30，币种 AUD。
- 两份收入合同；一笔期后签收形成截止错报 AUD 12,345.67。
- 五笔平衡凭证，审批记录完整；仅一笔同人审批形成控制复核事项。
- 一份银行回函，应计利息未入账 AUD 355.55。
- 两项错报一次登记管理层回复，一次通知两笔已过账调整，再执行更正验证。
- 补齐承接文件、合同、费用支持、银行回函、管理层回复和声明书。声明书及沟通记录通过人工文件上传入口办理，不绕过人工结果登记。

精简 mock 另提供一次计划退回和一次报告退回的固定修订分支，可独立演示，不叠加到默认路径。

每项判断程序通常产生一至两项复核；执行一次授权批次可合并处理同类建议。模型输出模式为 mock 时读取本数据集专属固定输出，不混用完整演示结论；live 模式实际请求配置的模型。生成脚本校验输入输出链接边界，导入时校验文件清单与 SHA-256。

接口契约及恢复规则见《开发接口文档》第 10.26 节。
