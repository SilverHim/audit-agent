## 方案取舍

- **期后窗口**: `LEAST(period_end + subsequent_days, COALESCE(data_as_of, period_end + subsequent_days))`. 写在一段 `bounds` CTE 里, 三条规则相同. 各行带 window_end.
- **"分类" 与 "类"**:
  - 需求写 "receivables 分类", "payables 分类", "property_plant_equipment 分类", 这些按 accounts.category 判.
  - "收入类", "资产或负债类" 按 accounts.type 判.
  - Xero 上两种写法结果相同.
  - 门槛与分类都写在 SQL 里, 不加参数, 参数快照恰为验收 1 的 8 项.
- **银行科目**: S01 与 S02 都用 bank_accounts.gl_account_code, 同一口径, 不另按 cash 分类.
- **S02 按窗口内的行归组成凭证**: 不要求整笔凭证都在窗口内, 一笔凭证的行同日, 实际没有差别. 取最大行, 并列取 ID 最小, 自然序编号, 都同 GEN-05 的通用约定.
- **S03 按行出例外**: 需求写 "单行借方超过". 编号按 (日期, 凭证自然序, 行 ID).
- **XERO_RULES 放在 xero_fakes.py**: 需求范围写 tests/fakes.py, 但 Xero 的预置现在都在 xero_fakes.py (GEN-05 也在那里), 故放在一起.
- **程序数断言改为集合包含 (按 X-01)**, 三处:
  - `test_evidence_gen08` 的 A5 程序集;
  - `test_knowledge` 的固定集;
  - `test_merge` 的 outputs 表.
  - 另在三处登记里补登 GEN-07: `test_knowledge` 的 DATASET_REFS, 作废对守卫的期望集合, 以及 `test_persistence_postgres` 跑全部规则 SQL 用的参数.
  - 断言内容都没改.
- **重放**: CSH-04 只声明函证与回函, 重放片段里没有 exceptions 键 (等于 []). GEN-07 的重放按 run_id 只取本次执行的例外.
