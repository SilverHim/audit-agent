# R184 确认材料: 意见类型可选范围 allowed_opinions (纯函数, 三处共用)

来由: critique C3, T8 推荐项, verify_G3 的候选意见意见 (临时编号 GC-51). 规模 S, 档位 xhigh. 分支 bing-r184, 原基于开发头 cd1e849, 严审修正时变基到 1d29aa9. 不改契约, 迁移与接口, 前端不用改.

## 改动摘要

- `services/opinion.py` (新): `allowed_opinions(*, total_cents, materiality_cents, going_concern) -> OpinionOptions(candidate, allowed, reasons)`, 纯函数, 只收它读的三项 (严审取舍 1); 另有 `AMOUNT_OPTIONS`. 第三项 (CHECK-FIN-18) 只在签名处写注释, 由 SG-16 加.
- `agents/qc.py`: A9 先按合计与重要性取 `allowed_opinions(..., going_concern=None).candidate`, 再一次构造汇总表, 不先填占位. A9 只走金额路径.
- `orchestration/gates.py`: `fin01_check` 改为调 `allowed_opinions(total_cents=汇总表合计, materiality_cents=其重要性, going_concern=None)`, 删去 FIN01_DISPOSITIONS 常量. 常量实际在 gates.py, 需求原文写的是 decisions.py, 按实际位置改. 不在可选范围时报 INVALID_VALUE, 消息列出可选的意见类型与理由. 闸门对象按 GateSpec.material_model 为汇总表, 用 isinstance 断言, 不用 cast.
- FIN-01 闸门材料 (`gates.fin01_view`) 本来不自己算候选, 呈报的就是汇总表 (CompletionMaterial.schedule.candidate_opinion), 候选随 A9 来自同一函数, 不用改.
- 接口文档:
  - 第 2 节汇总表的 candidate_opinion 与闸门决定的 disposition 两行注释;
  - 第 6 节 A9 的 FIN-04 一段, 并新增 "意见类型的候选与可选范围" 一段;
  - 第 7 节校验表的 INVALID_VALUE 行.
- 测试:
  - `tests/test_opinion.py` (新);
  - `tests/test_fin_gate.py`: 被拒用例的 detail 改为可选范围的消息, adverse 一例带金额路径的理由.
  - 原先替换函数的两个替身用例 (test_qc, test_fin_gate) 严审后删去 (R184-04), 由行为式断言与代码审核守住三处共用.

## 方案取舍

- **准则段号:** 用 pdftotext 核了 docs/参考资料/01_审计准则_ASA/ASA_570.pdf:
  - 第 21 段: 持续经营假设不恰当时发表否定意见;
  - 第 22 段: 存在重大不确定性且披露充分时发表无保留意见, 另加 "Material Uncertainty Related to Going Concern" 一节;
  - 第 23 段: 披露不充分时按 ASA 705 发表保留或否定意见.
  与需求一致. 理由里写 "ASA 570 para 21/22/23" 与 "ASA 450 para 11" (候选可推翻).
- **basis_inappropriate 的候选:** 候选取 adverse (第 21 段要求的), allowed 为 () (本版不支持, FIN-02 闸门已拒绝批准它). 这样 FIN-01 无论选哪种都会被拒, 消息带 "本版不支持持续经营假设不恰当 (否定意见)".
- **material_uncertainty_not_disclosed:** 候选 qualified, 金额已重大时同样为 qualified, 只可选 qualified. 否定意见本版不支持.
- **OpinionOptions 用 frozen dataclass:** 只在服务层传递, 不进状态, 不进接口, 不放 contracts.
- **reasons:** 每条路径一句, 先金额后持续经营, 写明合计与重要性的分值及准则段号. FIN-01 的拒绝消息带上这些理由.

3. 持续经营:
   - `test_material_uncertainty_disclosed_keeps_opinion_type`: Xero 4853 与 0 都为候选 unqualified, 可选两种; 金额重大时为 qualified.
   - `test_material_uncertainty_not_disclosed_needs_qualified`: 理由含 ASA 570 para 23.
   - `test_basis_inappropriate_allows_nothing`.
4. adverse 与 disclaimer 不可选: `test_adverse_and_disclaimer_never_allowed`, 覆盖 4 种合计 × 5 种结论 (含 None).

   - R55 全流程见默认全套与连库用例.
6. 开关无关: 函数不收功能集, 三处调用都不看功能开关.
