## 审核结论

第 1 轮严审通过 (6 条 minor, 2 条 nit), 按协调者裁定在 fix 提交里改:

- 01: 接口文档第 3 节重放规则的 singleton 列表加 ownership_graph (注明是第一个带 run_id 的), "片段含 singleton..." 的举例加关系图; 第 2.6 节列出 node_name_part. nodes.py 第 272 行注释留给 R137.
- 02: 节点 ID 格式不改. 第 0 节加个人信息提醒: 个人节点 ID 含出生日期 (yyyymmdd), 进提示词前换成不含出生日期的写法, 守卫两种写法都查.
- 03: node_name_part 先做 NFKD 分解再过滤 (José → JOSE, Zoë → ZOE); split_full_name 含逗号时按 "姓, 名" 拆; 姓规范化后为空时 person_node_id 抛 ValueError. 多词姓在全名拆分与姓名两栏之间的差异, 以及没有出生日期的同名者会并成一个节点, 写进第 0 节作为已知局限.
- 04: OwnershipGraph 加校验: 节点 ID 不重复, 报告主体与每条关系的两端都在 nodes 中. PartyNode 用 digits_problem 校验 ACN (9 位) 与 ABN (11 位) 的位数. company_node_id 先去掉空白, 之后不是 9 位数字抛 ValueError.
- 05: check_patch 加 `check_own_run`: 片段中带 run_id 而不带 procedure_id 的对象 (按模型字段判断), 其 run_id 须等于本次执行. 判断, 例外, 任务带 procedure_id, 可以是之前的执行写的, 不受影响.
- 06: 节点 ID 用例加含数字与非 ASCII 字母的两例与单名一例, 另断言 searched 缺省为假.
- 07: 删去慢用例里的单头检查. test_contracts 里的检查点 serde 往返删掉, 只留存储 JSON 往返. 重放用例删去 abn_calls 断言, 改用 FakeRegistry.
- 08: 没有 ACN 的公司的规则留给 R137, 本条不做.

新用例: `test_ownership_graph_is_closed_over_its_nodes`, `test_person_node_id_rejects_empty_family_name`, `test_ownership_graph_must_come_from_this_run`; `test_person_node_id` 加 3 例, `test_full_name_split_and_company_node_id` 加逗号拆分与 ACN 规范化的断言.
