## 讲解

### 业务背景

- brief 第 5 项: 演示默认数据集改为 Xero 演示公司 (xero/20261017-q1), Numbat 仍可选.
- 载入器按数据集自带的期间取试算表, 不读项目期间 (载入器接口说明). 所以 Xero 数据集建项目时, 期间须与快照一致, 否则项目期间与载入的数据对不上.
- 报告署名取项目负责人的姓名 (需求清单 Q15). 设计稿第 6.6 节的署名人是 Jordan Ellis, 而种子用户原名 Demo Auditor (critique C15(c), 第 4.3 节).

### 期间 (验收 2, 4)

- `XeroDatasetLoader.period`: `snapshot_period(快照)` 的本期起止.
  - q1 为 2026-07-01 至 2026-09-30.
  - mock 为 2026-07-01 至 2026-11-30.
  - 快照不存在或没有 dataset.json 抛 FileNotFoundError; dataset.json 缺键, 不是对象或日期写错抛 ValueError, 消息只写快照名, 不带服务器路径与文件内容.
- `CsvDatasetLoader.period` 与 `FakeDatasetLoader.period`: None (Numbat 由审计师填).
- `POST /engagements`:
  - 先取画像与期间: 不存在 404, 不合格 422 (原规则).
  - 期间不为空而请求的 (起, 止) 与之不同时 422 INVALID_VALUE, 消息为 "期间须与数据集 xero/20261017-q1 相同: 数据集 2026-07-01 至 2026-09-30, 请求 2025-07-01 至 2026-06-30", 不建项目.
  - demo 不比较.

### GET /datasets (验收 3)

- 每行在 dataset, legal_name, abn 之外加 period_start, period_end (可空) 与 default.
- default 为数据集名等于配置项 DEMO_DATASET. 不在清单时全为假.
- 画像或期间读不了的行跳过 (原来只跳过画像读不了的).
- 三个数据集:
  - xero/20261017-q1: {Demo Company (AU) Pty Ltd, 25900043021, 2026-07-01, 2026-09-30, default true}.
  - demo: Numbat 画像, 期间空, default false.
  - xero/20261017-mock: {Demo Company (AU), 11111111138, 2026-07-01, 2026-11-30, false}.

### 种子用户 (验收 6)

- `seed()` 新建账号的姓名为 Jordan Ellis. 已有同名账号时 `UserStore.create` 返回 None, 什么都不改 (幂等, 原约定).
- 新库演示时 RPT-03 的签字块取项目负责人姓名, 即 Jordan Ellis.

### 前端 (验收 7)

- 下拉默认选 default 为真的数据集, 没有时选第一个; 仍可选 Numbat.
- 所选数据集带期间时自动填起止日 (useEffect 跟随所选数据集的期间); 不带时回到 2025-07-01 至 2026-06-30.
- 清单加载中, 取数失败或为空时创建按钮禁用; 取数失败时表单里提示 (R79-05).
- 日期框仍可编辑. 改成与数据集不同的期间时, 后端按验收 4 拒绝, 前端照常提示错误.
- bun run lint (biome), bun run typecheck (tsc -b) 通过. generate-client 的产物与提交的相同.

### 测试

- `tests/test_demo_default.py`:
  - `test_demo_dataset_defaults_to_xero`: 配置缺省为 xero/20261017-q1.
  - `test_default_dataset_runs_to_acc01` (需要快照; 验收 5):
    - 装配: 组装根同样的数据集载入器 (带补造目录), 按项目数据集定位的登记 mock, 其余为假实现, 不连库.
    - GET /datasets 的默认行带出 q1 的期间, 按它 POST 建项目 (201), 总览客户名为 Demo Company (AU) Pty Ltd.
    - 跑到 ACC-01: SCORECARD 三项 (abn_active, name_match, company_registered) 都通过, external_call 2 行.
  - `test_seed_creates_jordan_ellis`: 替换存储与连接后调 seed(), 建的是 (登录名小写, Jordan Ellis); 与 NUMBAT_AUDITOR 同名.
  - `test_demo_created_with_any_period` (R79-01): demo 用 2024-01-01 至 2024-12-31 建项目 201, 项目期间为请求值, 跑到 ACC-01.
