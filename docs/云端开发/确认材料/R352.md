# R352 确认材料: 报告各段的段名只显示一次

## 改动摘要

- `lib/report-sections` (新): `reportPart(section, text, label)` 给出一段的段名与正文.
  - 意见段, 形成意见的基础段, 董事责任, 审计师责任, 其他法律法规要求五段: 正文首行即段名, 取首行作段名, 正文为其后各行 (只有标题行时为 "—").
  - 签名块: 正文不带段名, 用界面的段名.
  - 正文为空的一律用界面的段名, 正文为 "—" (现在模板里其他法律法规要求留空, 即显示界面段名与 "—").
- gate-form 的 `ReportPreview` (报告页与 RPT-01 闸门材料共用) 按它显示. 段名样式照旧, 正文不再重复首行.

## 方案取舍

1. **按段的种类定, 不比较字符串**: 哪几段的正文带段名是固定的, 不必比对文字.
   - 意见与基础两段的首行由 RPT-03 校验 (后端 REPORT_HEADINGS, 随意见类型变, 如 Qualified Opinion).
   - 模板 knowledge/templates/report.yaml 的各段按接口文档第 8 节的约定首行为标题, 签名块除外.
   - 前端列出这五段. 比较 "Opinion" 与 "Basis for opinion" 这类文字靠不住 (大小写, 保留意见的标题不同).
2. **取正文首行作段名, 不保留界面段名**: 段名随意见类型变 (Qualified Opinion), 正文里的才准. 中文界面这几段也显示英文段名, 与报告正文一致; 签名块等仍显示中文段名.
3. **RPT-01 的批注与退回表单照旧用界面段名**: 那里是指出批注挂在哪一段, 只出现一次, 不重复.
