## 讲解

### 业务背景

- 审计师发现错报后, 经 FIN-08 与管理层沟通. 管理层同意更正后, 在 Xero 里补录调整分录 (设计第 2.8 节, 第 7.2 节第 22, 29 步).
- 本数据集的更正分录分两轮, 共 5 笔 11 行:
  - 更正通知 1: AJE-X01 (撤销 #499), AJE-X05 (应计利息).
  - 更正通知 2: AJE-X02 至 X04 (养老金, 应计工资, 年假).
- 更正分录不在建项目时入库. 由更正通知 (MD-8) 按凭证号载入, 之后再由 FIN-09 验证.
- 本条只提供端口与实现, 使用方在错报闭环段 (R162, R163 等).

### 契约

- `load_adjustments(eid, dataset, entry_nos=None) -> list[JournalEntry]`:
  - entry_nos 是凭证号 (AJE-X01), 不是分录行 ID; 为 None 时载入文件中全部.
  - 返回所请求凭证的全部行, 按 id 排序 (已有的也返回).
- `adjustment_entries(dataset) -> list[AdjustmentEntrySummary]`:
  - 按凭证号自然序 (数字段按数值比), 每笔取首行的日期与摘要, 加行数.
  - 没有文件时为 [], 不抛错.
- `adjustment_entry_nos(dataset)`: 同上的凭证号, 供更正通知提交时校验.
- AdjustmentEntrySummary 是列表接口的返回值, 不进编排状态, 也不对应数据库表.

### `insert_adjustments` (TableLoader 公共部分)

- 事务之前, 只读文件:
  - entry_nos 为单个字符串时抛 TypeError.
  - 读 CSV 为 JournalEntry (空串按 None); 文件不存在抛 FileNotFoundError, 消息含路径; created_at 没有时区时抛 ValueError, 列出行 ID.
  - 请求的凭证号去重保序; 不在文件中的抛 LookupError, 消息列出编号.
  - 某笔借贷不平抛 ValueError, 消息列出凭证号.
- 一个事务内:
  - `writable` 锁项目行; 项目不存在抛 LookupError, 锁定抛 EngagementLocked.
  - 没有 dataset_loads 时抛 ValueError("尚未载入数据集"); dataset 与已载入的不同抛 ValueError.
  - 读出同 id 的已有行: 内容不同抛 ValueError, 消息列出行 ID; 相同的跳过.
  - 有新行时插入 journal_entries, 并把 dataset_loads.data_version 加一.
- trial_balance 不动. gl_balance 由分录算出, 所以更正后的余额直接反映出来.
- 拒绝的情况都在写入之前抛出, 事务回滚, 不留任何行.

### 各载入器

- CsvDatasetLoader (Numbat): 读 data/demo/adjustments/journal_entries.csv. 这个目录目前不存在, 所以抛 FileNotFoundError; 不为 Numbat 补数据. 第 9.3 节说的 "Numbat 只有一轮" 由使用方决定.
- XeroDatasetLoader:
  - `adjustments_path` 先核对补造目录 (R70), 再返回补造目录下的文件.
  - 没有补造目录时 (如 20261017-mock) 抛 FileNotFoundError, 消息含应有的路径.
  - adjustment_entries 在没有补造目录时为 [].
- RoutingDatasetLoader: 按数据集名前缀转发.

### 测试

- `test_adjustment_entries_and_numbers`:
  - demo 与 20261017-mock 为 [].
  - xero/20261017-q1 为 AJE-X01 至 X05, 行数 3, 2, 2, 2, 2 (合计 11), 日期都是 09-30, 摘要以 "Audit adjustment AJE-X01" 开头.
- `test_load_adjustments_rejects_before_writing`: 载入器没有数据库, 走到写入就会出错.
  - demo 与 mock 抛 FileNotFoundError, 消息含路径.
  - AJE-X09 抛 LookupError.
  - 借贷不平 (tmp 数据集里改 1 分) 抛 ValueError.
- `test_fake_loader_adjustments`: 假载入器按 id 排序返回, 记录调用, 未知凭证号抛 LookupError.
- `test_adjustment_inputs_are_checked`: 无时区的 created_at 与单个字符串都拒绝.
- `test_fake_loader_matches_real_semantics`: 假载入器凭证号自然序; 没有预置时载入抛 FileNotFoundError, 列表为空.
- `test_load_adjustments_two_rounds` (slow, 真实库):
  - 未载入时抛 "尚未载入数据集".
  - 载入后 journal_entries 1017, data_version 1.
  - [AJE-X01, AJE-X05] 插入 5 行 (逐行比对科目与金额), 1022, 版本 2; 同参数再调, 返回同样 5 行, 行数与版本都不变.
  - [AJE-X02, X03, X04] 插入 6 行, 1028, 版本 3; entry_nos 为 None 时返回 11 行, 不插入; 空列表返回 [], 不变.
  - 新项目上 entry_nos 为 None, 一次插入 11 行, (1028, 2), gl_balance 四个值相同.
  - gl_balance(2026-09-30): 620 为 4853, 270 为 -4853, 710 为 0, 820 为 -126697; 本期试算表与载入时相同.
  - 拒绝: 同 ID 内容不同 (把更正分录文件换成摘要改过的副本), 数据集不同 (项目载入的是 demo), 项目锁定. 都不改行数与版本.
- Numbat 回归: R55, R56 等连库测试照常通过.
