## 讲解

- **为什么没有改取对象函数的签名.** REV-02 的规则在 rev02_subjects 里执行, 结果要带到解读阶段. 改签名或另加返回值要改现有测试里替换的取对象函数. 所以用 list 的子类 Subjects 带 outcomes, 普通列表照常可用. 判断程序的原始发现由 list[Judged] 改为 JudgedRun. 没有测试直接造这个值, 只有 Agent 内部用.
- **为什么 finish_run 加参数而不是各处自己 model_copy.** 终态只在 finish_run 一处构造, 不经规则引擎的程序不传, 结果与之前逐字段相同.
- **回退旧代码的限制.** 新写的执行记录带 "rule_outcomes" 键. ProcedureRun 是 extra=forbid, 回退到本条之前的代码时读不了这些行 (存储与检查点都是). 只往前升级时没有影响: 旧行与旧检查点读回时 rule_outcomes 为空.
- **参数为 None 的写法.** psycopg 推不出 None 参数的类型. 只看参数的检查要写 `CAST(:名 AS 类型)`, 连库用例 (布尔, None, 字面量与参数作理由, 查表) 核对了这一写法.
