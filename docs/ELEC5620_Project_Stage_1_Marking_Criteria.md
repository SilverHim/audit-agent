# **Important Notes:** 

1. **The project requirement documentation must be included as part of the Stage 1 submission. All subsequent design and modeling tasks should be based on your project requirement to ensure consistency and alignment throughout the project.** 

2. **Titles marked with an asterisk (*) indicate that the task is an individual task, and each student must complete this part independently.** 

3. **Every group member must participate in all the group tasks. You need to specify group members’ individual contributions in the group tasks, e.g., clearly indicating which part(s) of the diagram is done by one student or the percentage of each member’s contribution.** 

4. **In all the individual tasks, the activity diagrams, interaction diagrams, and state machine diagrams you create must be based on your own ad hoc requirement analysis and the corresponding use case specification(s).** 

5. **Regarding the interview order, we will look at your submission time of Assignment 1 and use the reversed order to assign the time slot, i.e., the earlier you submit assignment 1 the later your time slot will be.**
