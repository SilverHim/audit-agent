# 合成数据集设计（demo）

B 按本文写生成脚本，产出 `data/demo/` 下全部文件。字段定义见 [开发接口文档.md](开发接口文档.md) 第 2、9 节，场景与验收见 [Demo需求文档.md](Demo需求文档.md) 第 3、8 节。

公司、人名、ABN、ACN、BSB、账号、地址全部虚构；ABN、ACN 通过官方校验位算法，ACN 取 9 字头号段。数据内容用英文。

**CSV**。列与第 9 节同名表逐列对应、去掉 engagement_id，列序如下：

| 文件 | 列 |
|---|---|
| accounts.csv | code, name, type |
| trial_balance.csv | period, account_code, balance_cents |
| journal_entries.csv | id, entry_no, posting_date, created_at, created_by, approved_by, account_code, debit_cents, credit_cents, description, source_doc, is_adjustment |
| sales_invoices.csv | id, invoice_no, customer, customer_abn, contract_id, invoice_date, posting_date, amount_cents, journal_entry_id |
| delivery_notes.csv | id, delivery_no, invoice_id, shipped_date, signed_date, signed_by |
| bank_accounts.csv | id, bank_name, bsb, account_no, gl_account_code |
| bank_transactions.csv | id, bank_account_id, txn_date, amount_cents, balance_after_cents, description, reference |

- UTF-8 无 BOM，逗号分隔，首行表头，LF 换行；含逗号的字段加双引号。
- 空值写空串，载入为 NULL；布尔写 `true` / `false`；日期 `YYYY-MM-DD`；时间戳 ISO 8601 UTC，如 `2026-06-28T11:14:00Z`。
- 金额为整数分。本文表格中带千分位与两位小数的是元，CSV 写 ×100 的整数；标 `_cents` 的列直接是 CSV 值。
- trial_balance.period 取 `current`、`prior`；balance_cents 借方为正。
- ABN 存 11 位数字、ACN 存 9 位数字，不带空格；PDF 中按 `68 900 042 015` 分组显示。

contracts、contract_terms、documents 三张表不由 CSV 载入：DatasetLoader.load 把 contracts/ 下的 PDF 经 `EvidenceStore.save`（type = contract，reliability = external_copy）登记，DOC-04 写合同与条款。回函 PDF 不载入，只由 ConfirmationChannel mock 读取。

**receipts.json**：

```json
{
  "12345601": {"receipt_channel": "direct_email"},
  "23456702": {"receipt_channel": "direct_email"}
}
```

mock 的 `submit` 按 `req.account_no` 读 `confirmations/{account_no}.pdf` 与本文件：sent_at 取当前 UTC 时间，replied_at 取 sent_at 的 Australia/Sydney 日期，reply_file_name 为 `{account_no}.pdf`。

**manifest.json**：生成脚本写出，供 A 写 fixture 时取 document_id。

```json
{
  "dataset": "demo",
  "seed": 20260630,
  "files": [{"path": "sales_invoices.csv", "rows": 624, "sha256": "…"}],
  "documents": [
    {"path": "contracts/CON-001.pdf", "type": "contract", "page_count": 3,
     "sha256": "…", "document_id": "DOC-{sha256 前 12 位}"}
  ]
}
```

**确定性**。同一种子重复生成，所有文件字节一致。PDF 用 reportlab 生成，`Canvas(..., invariant=1)` 固定创建时间与文件 ID。生成物提交进 Git；fixture 只引用第 5 节固定行与 manifest 中的 document_id。
