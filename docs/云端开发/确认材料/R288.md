# R288 确认材料: 客户登记与新建客户

来由: issue #7 (之一). 用户问 "项目为什么不能新建, 只能下拉框选择?". 原先新建项目的客户下拉取 GET /datasets, 每个数据集一行, 没有录入新客户的入口. 本条加客户列表与新建客户, 新建项目可选新客户; ABN 实时核查 (R289), ASIC 摘录 (R290), Xero 对照 (R291) 只留接口位置.

## 审核结论

规模 M, 档位 high. 开工前交了方案 (scratchpad/plan-bing-R288.md), 七题的裁定 (协调者, 10-19, 需求清单第 13 批):

1. Engagement.dataset 改为可空, 新客户的项目为 None. 依赖数据集的 mock 定位, fixture, 声明与预置都按 "没有数据集" 处理.
2. 不另建客户表. 客户即 client_profiles 里的一个 id, 新建客户即写画像第 1 版. 客户列表取各客户最新一版, 并上还没进库的数据集客户.
   - client_profiles 加 source (manual, dataset, update; 之后 xero) 与 updated_by 两列 (协调者同意的补充). 每一版记谁, 何时 (updated_at), 来源, 客户资料页的版本记录显示这三项.
   - 不另写 "新建客户" 留痕: audit_trail.engagement_id 是非空外键, 没有项目时写不了; 出处已在这两列里.
   - origin 取第 1 版的来源; 老版本没记来源时, 该 id 是数据集客户的记 dataset.
3. 新客户编号 CLIENT-M-{12 位十六进制}; 撞号报错, 不覆盖.
4. RegistryCheck.passed 改为 bool | None. 没接登记时为 None (待人工确认), 不出例外.
5. 来源老行显示 "未记录".
6. 新建客户表单只放 6 项必填, 备注与 4 个常用扩展字段 (财年末, 审批限额, 适用框架, 上期是否经审计); 其余扩展字段接口照收.
7. ABN 校验位与重复只在新建客户时查. ACC-01 改画像时的 ABN 校验并入 R289 (届时改测试里的假 ABN, 如 12345678901).
- mock 模式下新客户项目的大模型输出取默认 fixture (Numbat 底), 只供流程走通 (见讲解).
- 迁移编号 0011 (R279 占 0009, R277 占 0010).

## 讲解

- 客户放在哪里: 没有客户表, 客户就是 client_profiles 里的一个 id. 数据集客户在第一次建项目时才进库, 所以 GET /clients 要并上还没进库的数据集客户 (由 DatasetLoader 现算, 按画像 id 归并). 新客户的画像第 1 版来源为 manual. 以后每一版都记来源与写入人, 回答 "这个客户从哪来, 谁改过".
- 新客户的项目没有数据集: dataset 为 None 不是缺省值的写法, 是 "这个客户没有演示数据" 的意思. 用到数据集的地方都显式分支:
  - 登记 mock 不去猜目录, 抛 RegistryUnavailable. ACC-04 据此转人工确认, 不出例外, 审计师在 ACC-01 自己决定.
  - 函证 mock 出未回函. 计划预置用通用模板. 财务数据由审计师在数据管理页导入 (等数据的流程照旧).
- **mock 模式下的大模型输出**: 新客户的项目读 LLM_FIXTURES_ROOT (tests/fixtures/llm), 即 Numbat 的缺省 fixture.
  - 这只是为了在没有密钥时流程能走通. 合同抽取, 判断, 报告等输出的内容是 Numbat 的, 与新客户导入的数据对不上.
  - 要有意义的输出须用 live 模式 (配了模型与密钥). ACC-04 不调大模型, 不受影响.
- 待人工确认 (passed 为 None): 与 "未通过" 分开. 未通过出 high 例外; 待人工确认不出例外, 界面以黄色问号与 "待人工确认" 标出, 开场说明写明有几项要对照 ABN Lookup 与 ASIC. R289, R290 接上真实来源后, 这些检查自然回到 True 或 False.
- 查重与撞号: 同一 ABN (去空白后) 不能建第二个客户. 比较对象是各客户的最新一版 (客户在 ACC-01 改了 ABN 的以新的为准) 与数据集画像. 查重与写入在一把咨询锁内, 并发新建只成功一个. 编号随机, 撞号概率极小, 撞了就报错, 不覆盖已有客户.
- 给后续需求留的位置:
  - R289: RegistryUnavailable 的分支; 新建客户表单 ABN 下的提示位 (现在显示 "校验位正确 · ABN Lookup 在线核对尚未接入"); `abn_problem` 供 ACC-01 改画像时复用.
  - R291: ProfileSource 加 xero 即可记 "Xero 带出"; 更新画像走 save_profile 的 source 参数.
- 数据集客户不变:
  - 前端照旧发 dataset, 后端这条路径一行未改. 画像写入的唯一差别是多记了 source 与 updated_by 两列.
  - Numbat (R55, R56) 与 Xero 的回归测试照常通过.
