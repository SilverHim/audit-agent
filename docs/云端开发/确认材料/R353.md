# R353 确认材料: 走通用例的共用部分移出测试文件

来由: 协调者审读 R345 (10-20). 规模 S, 档位 high (只改测试, 免审). 父提交为 R317 的审核修正 7854f67 (R317 合入后变基). 一并做了 R317 审核意见 10 (离线依赖的装配抽成共用函数). 只搬家, 不改行为.

## 改动摘要

- 新模块 `tests/live_walk.py`: 原在 `tests/test_demo_walkthrough_live.py` 的驱动, 汇总与检查原样搬来. 包括:
  - 决定表与任务决定: decision_table, review_body, dispute_fields, REVISED_BY;
  - 驱动: drive, LiveWalk;
  - 汇总与检查: evaluate, unresolved_pointers, latest_model_judgments, assert_hard, warn_soft;
  - 用量: FIXED_CALLS 之上的 LIVE_MARGIN 与 MAX_CALLS.
- 引入它的: HTTP 的真实模型变体 (`test_demo_walkthrough_live`), 浏览器走查 (`tests/e2e/test_browser_walk`), Xero 程序级评测 (`test_eval_xero_live`).
- 原在测试文件里, 被这几处引用的小件也挪到非测试模块:
  - `tests/fakes.py`: CreatingEngagementStore (原 test_demo_default), evidence_pointers (原 test_e2e_mock). 后者改为取项目依赖 (deps), 不再要 test_decisions.Started.
  - `tests/xero_fakes.py`: XERO_PERIOD (原 test_e2e_xero17).
  - `tests/xero_flow.py`: API, xero_link (原 test_demo_walkthrough) 与新的 demo_offline.
- demo_offline: 离线演示项目的依赖, runner, 数据服务与登录的接口客户端. 走通用例的 walked 夹具与真实模型变体的 offline_walk 共用 (R317-10). 原来两处装配的代码逐字相同.
- 原定义处改为从新位置引入; test_clients, test_client_profile_api 的 CreatingEngagementStore 也改从 fakes 引入.

## 方案取舍

- 新建 `tests/live_walk.py`, 不并进 `tests/xero_harness.py`: 后者是程序级测试台 (按层直接调 Agent, 不经主图). 走通的驱动经 HTTP 走全流程, 并进去会让一个模块管两种走法.
- 余下的测试文件互相引入, 都是本条以前就有, 本条不动. 在引入处写了理由:
  - `test_e2e_mock.real_storage`: 连库装配, R56 起另有五个测试文件共用, 搬它超出本条范围;
  - `test_e2e_xero17` 的 R119 断言函数: 走通用例按 R119 的计数断言;
  - `test_demo_default.demo_runner`: 演示默认数据集的装配, 按客户排序的用例用.
- 全仓库的测试文件互相引入还有约 260 处, 不在本条范围.

## 验收对照

1. 走通相关的文件 (live_walk, xero_flow, 浏览器走查, 真实模型变体) 不再从测试文件引入驱动与汇总. 余下的引入见上一节, 每处在引入行写了理由.
2. 默认全套通过; 两个走通的 mock 与连库变体通过, 计数不变. 见下.
