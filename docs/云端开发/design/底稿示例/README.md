# 工作底稿示例

用户 10-21 确认的底稿设计示例, 供 Issue "工作底稿" 实现时参照版式与必备内容。数据取自演示项目 ENG-2026-001 (Xero 演示公司) 10-20 的实际运行结果; 测试明细中的逐张结果由规则口径复算, 与系统查出的例外一致。

- 全部用 Excel; 一个程序一份底稿, 每份一个文件; 索引 (`00 索引.xlsx`) 逐程序编号并链接到各文件。
- 示例生成了 7 份: 索引, A-2 重要性, D 收入导引表, D-2 收入合同条款评价 (判断类), D-3 凭证三单匹配 (规则类), X 错报汇总, S 准则对照; 其余在索引中标 "本示例未生成"。
- D-2 的判断文字按 "工作语言: 中文" 由人工译出 (系统当时输出英文), 合同原文保留英文。
- 生成脚本: `build_sample.py` (版式与数据), `contracts_data.py` (D-2 的数据)。

依据: ASA 230 第 8, 9 段与附录 1 (准则对照中的段号按各准则现行文本; ASA 230 附录 1 中 ASA 240, 250, 260 的段号为修订前编号); 结构参考 IFAC《Guide to Using ISAs in the Audits of SMEs》第 4 版第二卷的案例底稿 (只参考结构, 未照搬)。
