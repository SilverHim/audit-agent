# R354 确认材料: 回函应计利息截至余额日已计的不论何时支付都取

来由: R345 浏览器走查第一次用真实模型跑 (ENG-2026-1140), DOC-06 把储蓄户 12345679 回函的应计利息 48.53 抽成 null, CSH-02 BA-091 因此缺模型结论. 回函原文: 截至 09-30 已计, 写明以后某日支付. 旧提示词说 "不取以后某日应付的整期利息", 模型把两者混淆了. 规模 S, 档位 high. 父提交为开发头 b425599.

## 改动摘要

- `knowledge/prompts/DOC-06.md.j2` 的 accrued_interest_cents 一段:
  - 新加一条: 写明截至余额日已计而未入账的金额就取, 不论何时支付. 写明以后某日支付或记入, 或属跨过余额日的计息期, 都不影响.
  - 不取的只是: 已入账的利息, 余额日之后才计的利息 (如下期利息).
  - 回函只写整期利息, 没写截至余额日已计的部分时为 null, 不自行计算 (同 "只取原文写的, 不推算" 一条).
  - 加一个同型正例: 别的日期与金额, 计息期跨余额日, 以后记入 → 取.
- `tests/test_ingest_doc06.py` 的口径关键词表 ACCRUED_RULES 随之改: "不取以后应付的整期利息" 换成 "不论何时支付都取", "不取余额日之后才计的", "只写整期时为 null", "不自行计算". 旧提示词在新表下不过.
- 接口文档第 6 节 ConfirmationExtraction 一行的口径同步.

## 方案取舍

- 只写整期利息的回函仍为 null, 不让模型按天数折算: 提示词第一条规则是 "只取原文写的, 不推算"; 折算出的数不是银行确认的. 演示两份回函都写明了截至余额日的金额, 不受影响.
- 正例只给 "要取" 的一种. "不取" 的几种都写成规则, 不另举例, 免得例子多了模型照例子套.
