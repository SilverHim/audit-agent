## 版本口径

**ASA / ASQM**：取当前有效版本（生效日 ≤ 2026-09-21 中批准日最新者）。唯一例外是 `ASA_240_（2026-12-15起生效）.pdf`，反舞弊责任新版尚未生效，与现行 ASA 240 并存，两版都在。

**AASB**：取 2025/26 财年（2025-07-01 至 2026-06-30）适用版本。

**Corporations Act 2001**：编纂版 C148，编纂日 2026-08-27。**第 2M 章"财务报告与审计"（s285–346）在第 2 卷**（该卷覆盖 s283AA–600K）。审计师任命与报酬 s327–331、审计师独立性 s324CA 及以下、审计师报告义务 s307–308、向 ASIC 报告违规 s311 均在此卷。

**ASIC**：RG 26（审计师辞任与更换）、RG 34（向 ASIC 报告义务）、RG 187（审计师轮换）、RG 260（审计发现通报）、REP 819（2024–25 年度财报与审计监督报告，含审计档案检查结果）。

**APES 110**：2025 年 7 月编纂版，含截至该月全部 11 项修订，其中可持续鉴证修订自 2026-01-01 起生效。

## 更新

准则每年修订，AUASB 与 AASB 均在官网发布新编纂版。重新下载的脚本逻辑记录在各目录隐藏的 `.manifest_*.json` 中（含每份文件的来源 URL），按其中的 URL 模式重抓即可。
