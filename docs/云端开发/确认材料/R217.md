# R217 确认材料: 待审财报的上传抽取, 端口与存储

## 改动摘要

- 契约:
  - `FinancialDataStore` 加三个方法: `financial_statements` (当前版本), `save_financial_statements` (写一版), `statements_history` (各版).
  - `record("financial_statement_line", 行代码)` 取当前版本中的该行, 带 fs_id 与 fs_version.
  - 新输出模型 `StatementsExtraction`: FinancialStatements 去掉 id, version 与 document_id.
  - 新常量与字段: `DataInput.financial_statements`, `FS_TARGET`, `DocumentChange.financial_statements`, `BatchItem.statements`.
- 存储:
  - 表 financial_statements 与 financial_statement_lines, 迁移 0019 (down_revision 0018).
  - Postgres 实现, 写入共用 `write_statements`. 智能导入确认时 `commit_batch` 同样写入.
- A3 (`agents/ingest.py`):
  - 模板 `STATEMENTS` (DOC-STATEMENTS), 不进程序库, 同 CLASSIFY; 提示词 `DOC-STATEMENTS.md.j2`.
  - 上传或批次识别时抽取, 写新一版, 同一事务数据版本 +1.
- 修改: `DataService.edit_financial_statements` 与 `apply_statements_edit`. 接口 GET/PUT `/financial-statements` 与 GET `/financial-statements/history`. 前端客户端已重新生成.
- fixture: `tests/fixtures/llm_xero/DOC-STATEMENTS/fs_v1.json`, 运行副本经生成脚本同步. 接口文档第 2, 4, 5, 6, 8, 9, 10 节已同步.

## 方案取舍

- **当前版本按来源文件取**: 取来源文件现在仍登记为 financial_statements 的各版中版本最高的. 依据验收 5 的 "没有已抽取的 financial_statements 类文件时为 None". 文件改成别的类型后为 None, 改回来恢复.
- **输出模型不含系统字段**: id, version, document_id 由系统补上. 所以 fixture 是 fs_v1.json 去掉这三项, 有守卫用例逐字段核对.
- **只做语法与结构校验**: 报表不作证据, 没有指针. 各行与科目余额勾不勾得上留给 FIN-12.
- **只抽 PDF 报表**: Excel 草稿等停在 classified, 待审财报仍为空. 这样 R277 "报表草稿工作簿" 的现有行为不变. 若要它们转 needs_manual, 只改 `needs_extraction` 一处.
- **补做**: 作业开始之后已有新版本时不重抽. 来源是本文件的算做完, 是别的文件的转人工, 同合同的规则.
- **可改的字段**: 编制日, 董事声明日, 各行的名称, 本期金额与比较数. 行用行代码指定, 如 `lines[SOFP-OREC].amount_cents`.
  - 映射科目与比较数凭证号是列表, 而 ExtractionEdit 的值只能是文本, 整数或空. 本条不改契约, 两项只读.
- **范围之外的改动**: 前端上传补交资料走智能导入批次, 所以批次路径也带上了抽取结果 (Staged, BatchItem, DocumentChange, commit_batch). 同一批两份报表时, 后一份的版本接在前一份之后.
- **端口方法**: 写入与历史各加一个端口方法, 先例是 save_contract 与 contract_history. 读写都在 FinancialDataStore, 假存储也就自洽.
- **体检的 "已提供"**: 抽取没通过转人工的财务报表 (needs_manual, extract) 也算已提供, 补交请求照样转 received. 客户已经交了, 抽取由审计师处理 (`checkup.statement_provided`).
  - 否则 R15 的两个用例会回退: 上传的占位 PDF 没有固定输出, 抽取失败, 请求一直 open.
  - 改了这两个用例里文件状态的断言, 改为 needs_manual (extract).
