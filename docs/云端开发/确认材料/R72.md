## 改动摘要

- `XeroDatasetLoader.tables(dataset)` (`persistence/stores.py`): 不连库的纯函数, load 在载入事务内调用它.
  - 先核对补造目录 (沿用 R70).
  - 再在快照映射出的七张表上并入补造表, 合同 PDF 取补造目录的 contracts/.
  - 没有补造目录时与纯快照相同, 不登记合同.
- `Supplements` (`adapters/xero_supplements.py`) 新增三个方法:
  - `contracts()`: 合同 PDF 列表.
  - `rows(name)`: 读补造 CSV.
  - `apply(tables)`: 合同关联, 服务完成记录, 开户行并入财务表; 对不上时抛 SupplementMismatch.
- 接口文档第 4 节 DatasetLoader 实现说明; 设计第 3.1 节与第 9.3 节第 6 项.
- 测试:
  - `tests/test_xero_supplements.py` 加 4 个用例, 参数化后共 13 组.
  - `tests/test_dataset_loaders.py` 加 1 个用例.
  - `tests/test_persistence_postgres.py` 加 1 个慢测试.

## 讲解

### 业务背景

- Xero 没有合同, 也没有发运或服务完成记录; 开户行名 API 也不提供, 只能取科目名称.
- 这些由 R65 补造:
  - 合同 CON-X01 至 X03 的 PDF.
  - contract_links.csv: 6 张发票挂到 3 份合同.
  - delivery_notes.csv: 24 条服务完成记录, ORC1003 与 ORC1005 没有.
  - bank_accounts.csv: 开户行 Wattlebrook Bank Limited.
- REV-02, REV-03, DOC-04 (合同条款抽取), CSH-04 (按开户行发函) 都要用到这些.
- 本条让载入器把它们并入系统财务表 (设计第 3.1, 3.3 节, 第 9.3 节第 6-9 项).

### `Supplements.apply(tables)`

- **发票号对照**: 由快照的 sales_invoices 建立 "发票号 → SI- ID". 发票号在快照中找不到, 或出现不止一次, 都抛 SupplementMismatch, 消息含文件名与发票号.
- **合同关联**:
  - contract_links.csv 每行把对应发票的 contract_id 设为合同编号.
  - 同一张发票出现两次时报 "重复"; 合同编号不在 contracts/ 中时报 "没有 PDF".
  - 其余发票保持 None.
- **服务完成记录**:
  - delivery_notes.csv 每行写成 DeliveryNote: id 与 delivery_no 都是 SR-{发票号}, invoice_id 为 SI- ID.
  - 空日期与空签收人写 None.
  - id 或发票重复时报 "重复".
- **开户行**:
  - bank_accounts.csv 只许覆盖 bank_name.
  - id 不在快照, 或 BSB, 账号, 科目与快照不同, 都抛 SupplementMismatch, 消息含账户 ID; 同一 id 两行报 "重复".
- **格式**: 三份 CSV 缺列, 日期格式不对或模型不合时, 抛 "<文件> 缺列或格式不对", 不带出文件内容.
- **何时暴露**: 这些内容核对在载入时 (p1_ingest) 做, 失败记入 run_error. 建项目接口与 GET /datasets 只做哈希核对; 正式目录哈希相符时, 内容已由校验脚本核过.
- 其余四张表 (accounts, trial_balance, journal_entries, bank_transactions) 原样返回.

### `XeroDatasetLoader.tables` 与 load

- tables 依次做三步:
  1. supplement(dataset) 核对.
  2. build_tables(快照).
  3. 有补造时调 apply, 并返回 contracts().
- load 改为 `insert(eid, dataset, lambda: self.tables(dataset))`.
  - 已载入的项目不调 tables, 补造与快照都不读 (R70 的行为不变).
  - 合同由 TableLoader.insert 经 EvidenceStore.save 登记为 contract, external_copy.
  - 文件 ID 是 DOC- 加 sha256 前 12 位, 与 manifest.documents 的 document_id 相同.
  - ingest.contract_id 取文件名主干, 得 CON-X01 等.
