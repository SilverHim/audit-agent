# R323 确认材料: 测试的 git 子进程不继承钩子里的 GIT_* 环境

## 改动摘要

- `tests/external.py` 的 `git_lines` 调 git 时传 `env=git_env()`, 复用 `backend.services.procedure_library.git_env` (去掉全部 GIT_* 变量; 程序库取提交号时已这样做).
- `tests/test_external.py` 新增 `test_git_hook_environment_does_not_leak_into_other_directories`.

## 方案取舍

- 复用现有的 `git_env`, 不在测试辅助里另写一份过滤: 同一问题同一个函数.
- 去掉全部 GIT_* 而不是只去 GIT_DIR, GIT_WORK_TREE, GIT_INDEX_FILE: 钩子还会设 GIT_PREFIX 等, 一并去掉最稳妥, 与 git_env 的口径相同.

## 验收对照

1. `git_lines` 的子进程环境不含 GIT_* 变量.
2. 以 GIT_DIR, GIT_WORK_TREE, GIT_INDEX_FILE 指向本仓库跑 `test_snapshot_functions_skip_without_a_snapshot`: 修复前失败 (复现), 修复后通过.
3. 新用例: 同样的环境下临时空目录 `tracked("data")` 为空, `main_checkout` 为 None, 本仓库 `tracked("CLAUDE.md")` 照常; 去掉修复时该例失败.

## 审核结论

免审 (只改测试辅助与测试).
