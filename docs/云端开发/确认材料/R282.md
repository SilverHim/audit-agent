## 讲解

### 卡片的状态 (验收 2, 3)

| 概览 sources.xero | 显示 | 按钮 |
|---|---|---|
| not_connected | 未连接 | 连接 Xero |
| connected, 已选组织 | 组织, 最近同步, 接入范围; 授权给到多个组织时另有 "要同步的组织" 下拉, 可以换 | 重新同步, 断开连接 (点了再确认) |
| connected, organisation 为空 (授权给到多个组织, 未选) | 组织 "尚未选定"; 下拉的占位为 "选择组织…"; 说明 "这次授权给到了多个组织, 先选定要同步的组织再同步" | 重新同步置灰, aria-describedby 关联说明; 断开连接 |
| expired | 状态 "授权已失效" (警示色); 组织等信息照旧显示; 说明 "Xero 授权已失效 (刷新令牌过期或已在 Xero 撤销), 请重新连接后再同步" | 重新连接 (关联说明), 断开连接 |
| 同步中 (`syncing` 为真, 首次同步与再次同步都是) | 按钮转圈, "同步中…" | 同步, 下拉与断开置灰 |
| 有上次同步 (`last_sync`) | "上次结果": 失败为 "同步失败 (原因), 时间"; 成功而有没写的表时逐项 "…未写入: 原因"; 否则 "成功" | — |

组织列表取 GET /data/xero/tenants (连接时存下的, 后端不调 Xero), 只在 connected 时取, 不重试. 当前选定的组织按概览的 tenant_id 在列表里找. 同步中与否, 选定的是哪个组织, 上次同步的结果, 都取概览, 前端不从表的来源与状态推断.

### 操作与提示

- 连接: 取 GET /data/xero/connect 的授权地址, 整页跳到 Xero.
- 回调: 后端 302 回本页, 带 `?xero=connected` 或 `?xero=error&reason=<原因代码>`, 本页提示一次后清掉参数.
  - 原因代码 denied, state_invalid, state_used, state_expired, not_found, locked, busy, exchange_failed, no_organisation, settings_key, internal_error 各有中英文案, 不认识的代码用通用的 "Xero 授权未完成".
  - 同一提示用固定的 toast id, 开发模式下 StrictMode 把 effect 跑两次也只显示一条.
  - 认不出项目的回调回首页, 转到项目列表时带着参数, 同样提示.
- 连接, 同步, 选组织, 断开共用一个提交中标记: 进行中再点不发请求 (连点的第二下在重渲染之前就到, 不能只靠 isPending), 进行中这四个控件都置灰; 连接成功后整页跳到 Xero, 标记不复位.
- 选组织: PUT /data/xero/tenant, 提示 "已选定 Demo Company (AU)", 刷新本项目数据.
- 同步: POST /data/xero/sync 返回 202, 提示 "已开始从 Xero 同步"; 进度看概览, 有进行中的作业时每 3 秒轮询 (原有).
- 断开:
  - 点 "断开连接" 出确认对话框 (说明会删令牌并向 Xero 撤销, 已同步的数据保留), 点 "确认断开" 才发 DELETE; 点对话框外不关闭, Esc 与取消关闭.
  - 成功后先把概览缓存里的连接置为未连接并丢掉组织列表, 再刷新本项目数据, 不再去取已删连接的组织.
  - DELETE /data/xero 返回 revoked 为 true 时提示 "已断开 Xero".
  - 为 false 时警告 12 秒: "本地的连接与令牌已删除, 但 Xero 没有确认撤销授权, 请到 Xero 的 Connected apps 中手动移除本应用".
  - 授权失效的连接也能断开 (后端撤销不了, 返回 false, 同样提示).
- 出错按错误码给本地文案 (`errorText`): 未连接, 多组织未选, 授权失效要重新连接, 后端没配 Xero 应用, 暂时连不上 Xero, 加密主密钥没配或不对.

### 时间线 (工作区)

| 留痕 action (R279) | 中文 | 英文 |
|---|---|---|
| xero_connect | 已连接 Xero (组织名); 多组织未选时为 "已连接 Xero, 待选组织" | Xero connected (organisation) / organisation to be chosen |
| xero_tenant | 已选定 Xero 组织 Demo Company (AU) | Xero organisation ... chosen |
| sync (每表一条) | 已从 Xero 同步科目表 62 条 | Chart of accounts: 62 records synced from Xero |
| xero_synced (有没写的表时) | Xero 同步未写银行账户, 银行流水 (对账单接口无权限 / 未开通付费接口) | Xero sync left out ... (...) |
| xero_sync_failed | Xero 同步失败 (授权已失效 / Xero 报错 / Xero 拒绝读取部分资料 / 加密主密钥不可用 / 数据无法转换 / 写入数据时出错) | Xero sync failed (...) |
| xero_disconnect | 已断开 Xero; Xero 侧未撤销时另注明 | Xero disconnected (not revoked in Xero) |
