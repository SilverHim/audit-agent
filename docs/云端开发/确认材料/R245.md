# R245 确认材料: CUAD 下载脚本与来源说明

来由: R286 (演示合同以 CUAD 为底稿改写) 的前置. 协调者裁定先把本条做成单独一个小提交, R286 缺 CUAD 时的提示直接给出这里的取数命令.

## 审核结论

规模 S. 协调者定为改完不另审.

## 改动摘要

- `tests/tools/__init__.py` (新): 测试与数据准备用的命令行工具包.
- `tests/tools/cuad_fetch.py` (新): `uv run python -m tests.tools.cuad_fetch [--dest data/external/cuad]`.
  - `ensure_cuad(dest, *, client=None, today=None, expected_md5=MD5)` 返回 `dest/CUAD_v1`. 失败抛 `CuadFetchError`, 失败时目标目录与临时文件都已清理.
  - 真实下载的客户端由 `make_client()` 建: 跟随跳转, `trust_env=True` (读环境里的 HTTPS 代理与 CA), 不关 TLS 校验.
- `tests/test_cuad_fetch.py` (新): 14 个默认测试 (httpx.MockTransport 给假 zip, 不联网) 与 1 个慢测试 (只在 CUAD_FETCH=1 时真下载).
- `docs/云端开发/开发提示词.md`, `计划-第1至3级.md`: 讲到 CUAD 下载的那一句加上取数命令.

## 讲解

- **下载与校验:**
  - 流式写到 dest 下新建的临时目录 `.cuad-download-*`, 边写边算 md5.
  - md5 不符就报 "md5 为 {实际}, 应为 c38f490a984420b8a62600db401fafd5", 删掉临时目录. 本次新建的 dest 也一并删掉; dest 原先就有时, 原有文件不动.
- **解压:**
  - 先查全部条目, 再动手. 有绝对路径 (含 `/x`, `C:/x`), 含 `..` (含反斜杠写法) 的条目就整包拒绝, 一个文件都不写.
  - 解压到 dest 下新建的空临时目录 `.cuad-extract-*`, 再把其中的 `CUAD_v1/` 整体改名为 `dest/CUAD_v1`. 同一文件系统内改名, 不会留下半个目录.
  - 压缩包里没有 `CUAD_v1/` 时报错.
  - 解压出的文件只当数据读, 脚本不执行, 不导入.
- **来源记录:**
  - 解压后写 `dest/README.md`: 来源 (Zenodo 记录 4595826 与链接, 版本 v1, 取数命令), 署名句, 许可名与链接, CUAD README 的免责原句, 下载日期与 md5, 解压方式, 不入库.
  - "已存在且记录的 md5 相符" 以 README 里 "CUAD_v1.zip 的 md5 为 ..." 一句为准. 相符时直接返回, 不发请求.
  - `CUAD_v1/` 在但 README 没有相符的记录时报错, 不覆盖, 由人核对后删掉再取.
- **默认测试不联网:**
  - 本文件有自动用的夹具: 未标 slow 的测试里, `make_client` 一被调用就失败. 所以默认测试只能经 MockTransport 下载.
  - 其他测试文件都不导入本模块.

## 验收

1. 下载走已配置的 HTTPS 代理, 不关 TLS 校验; md5 不符即报错且不留目标目录.
   - 真实运行: 本机先删掉手工取的副本再跑 CLI, 约 25 秒完成, md5 c38f490a984420b8a62600db401fafd5; 再跑一次输出 "已有 CUAD (md5 相符), 不再下载".
   - test_md5_mismatch_fails_without_leftovers: 假 zip 的 md5 不是正本的, 报错, dest 不存在.
   - test_failure_keeps_an_existing_dest_but_leaves_nothing_in_it: dest 原先就有文件时, 只剩原有文件.
2. 先解压到同级新建的空临时目录, 拒绝绝对路径与含 .. 的条目, 再整体改名.
   - test_unsafe_entries_are_rejected_without_leftovers 参数化 5 种条目: `../x`, `CUAD_v1/../../x`, `/etc/x`, `C:/x`, `CUAD_v1\..\x`. 都被拒绝, tmp_path 下什么也没留.
   - test_archive_without_cuad_dir_is_rejected: 压缩包里没有 CUAD_v1/ 时报错.
   - test_downloads_checks_extracts_and_writes_readme 断言成功后 dest 下只有 `CUAD_v1` 与 `README.md`.
3. README 含来源 Zenodo 4595826, 版本 v1, 署名句, 许可链接, 免责句, 下载日期与 md5.
   - 免责句与 CUAD_v1_README.txt 的原句一致, 由慢测试 test_real_download 对真实文件核对.
4. 已存在且记录的 md5 相符时不再下载; `git check-ignore` 判为忽略.
   - test_second_run_sends_no_request: 第二次运行 0 个请求.
   - test_existing_target_without_matching_record_is_left_alone: 目录在但记录不符时报错, 0 个请求, 原样不动.
   - test_default_dest_is_git_ignored: `git check-ignore -q` 对 data/external/cuad/CUAD_v1 与 README.md 都返回 0; 不是 git 检出时跳过.
5. 单测不联网 (httpx.MockTransport): 见上. 另有 test_http_error_fails_without_leftovers (HTTP 404 报错, 无残留) 与 test_cli_reports_errors_and_reuses_a_recorded_copy (CLI 出错退出码 1 并在 stderr 报原因; 成功退出码 0; 第三次不再请求).
6. 默认 `uv run pytest` 与任何测试都不调下载:
   - 只有显式运行 CLI, 或 `CUAD_FETCH=1 uv run pytest -m slow tests/test_cuad_fetch.py` 才会调 ensure_cuad().
   - 本机 CUAD_FETCH=1 跑过, 通过 (已有副本, 只核对). 不设时跳过.
