## 方案取舍

- eqr_basis 用登记行的 check 校验, 不加到 PlanConfirmation 的模型约束上: 错误码照校验表为 INVALID_VALUE (模型约束会在 API 层变成 422 的请求体错误), 契约也不变.
- auditor_expert_not_required 为假, eqr_required 为真都照样通过, 只记录. 本版没有审计师专家程序, 签字闸门也不查项目质量复核.
- 验收 2 的批准放在驳回之后批 PLAN-2, 不为它再跑一遍全流程. 重启也挪到驳回之后 (停在 PLAN-2 v1), 同时覆盖 R205 "停在闸门时重启" 的原断言.
- 第 2 修订仍借第 1 修订的固定输出 (SecondPlanAsFirst). r2.json 由 R316 加, 加了以后再换.
