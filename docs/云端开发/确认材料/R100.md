## 讲解

- 为什么要分录行: 含 GST 的发票金额包含应付税款, 收入只记不含税的那一行 (如发票 715000 = 收入 650000 + GST 65000). 截止错报的金额应是多记的收入, 不是整张发票. 以前上下文里没有分录行, 模型只能拿发票金额; 现在可以引用收入行, 校验器按 "被引用的行金额" 认可 650000. 不引用该行时 650000 仍被拒, 校验没有放宽.
- 服务业务: 发运单的两列在服务业务里借用为 "服务开始" 与 "客户确认完成"; 随时间转移的服务 (AASB15-P35) 按服务期间分摊, 一张发票跨期时要更多证据.
- 没有合同不再是要更多证据的理由: 很多销售没有书面合同, 发运或服务完成记录本身就能定转移点. 输入里仍照实写 "No contract is linked to this invoice."
- 收款类例外 (R03): 收款金额不符说明的是收款与对账, 不能单凭它认定截止错报, 但推理链要回应它.
