## 方案取舍

- 遮蔽放在 ToolBox.call 的出口: 所有工具 (含以后的 GEN-08 关系图工具) 都经这里, 不逐个工具改.
  - 遮的是整段 JSON 文本, 不是逐字段: ID 出现在键, 值, detail 的嵌套列表与错误文本里, 都能覆盖.
  - ID 只含 A-Z, 0-9 与连字符, 不会破坏 JSON.
- 遮蔽后的写法直接去掉日期段. 用不可逆的编号要另存对照表; 用日期的哈希也不行, 日期只有几万种, 能反推.
  - 同名而出生日期不同的两人遮蔽后相同, 同文档里已写的 NODOB 局限一起写明. 后续需求若要求区分, 再给两人编序号.
- 先遮蔽再截断: 先截断时截口若落在日期中间, 留下的半截日期正则认不出, 会漏出去. 有专门一例.
- birth_date 字段直接去掉 (同 engagement_id), 不改成别的值: 模型用不到出生日期.
- 发给模型的就是遮蔽后的文本: 对话留痕 (llm_call) 记的也是它; 字符预算按遮蔽后的长度算.
