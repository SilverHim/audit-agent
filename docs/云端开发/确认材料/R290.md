# R290 确认材料: ASIC 摘录上传, 抽取与 ACC-04 核对

来由: issue #7 (之三). ASIC 摘录一般要付费购买, 由审计师上传, 不接 ASIC 接口. 新建的客户 (没有数据集, R288) 上传摘录后, A3 抽取; ACC-04 用抽取结果核对 "公司已注册", 名称与董事名单. 是公司而还没有摘录时, ACC-04 之前先等摘录 (R272 的程序等数据), 审计师也可以标 "客户无此类资料" (R280).

### 开工前的方案裁定

规模 M, 档位 xhigh. 开工前交了方案 (scratchpad/plan-yi-R290.md). 协调者 10-19 裁定十题都取推荐项 A (需求清单第 13 批 "R290 方案"):

1. 主图在 ACC-04 前加节点 p0_inputs.
   - 有数据集的项目直接通过.
   - 新客户先查一次 ABN (留痕). ABN 登记有 ACN, 没有 ASIC 摘录, 也没标客户无此类资料时: ACC-04 记 awaiting_data, 按 R272 等待, 资料到了自动继续.
   - ACC-01 的 rerun 出口改回 p0_inputs. 单独成节点, 免得与 p0_intel 里 "失败等人" 的 interrupt 串了恢复值.
2. 标了客户无此类资料时 ACC-04 照常执行, 公司两项待人工确认, 不记 no_data (ACC-01 闸门要评分卡).
3. 新客户的 company_registered 由摘录判定: 状态 Registered, ACN 等于 ABN 登记的 ACN, 名称规范化后相同. name_match 仍比 ABN 登记.
4. 新加 directors_match, 只对新客户. 比画像董事与摘录中 director 的姓名集合, 不比秘书; 不一致出例外. 数据集客户回归不变.
5. 证据指针指向上传的摘录文件, 可靠性取文件登记.
6. A3 抽取通过即可用. 修改出新版本, ACC-04 取最新一版, 不另加确认动作.
7. 新的代码内抽取模板 DOC-REGISTRY (大模型, 同 DOC-CLASSIFY, 不进 17 条). AsicExtract 加可空的 abn 与 registered_address. 补造数据不改. 抽取结果存抽取版本表, 不加迁移.
8. 可改登记字段与高管的姓名, 职务, 任职日, 不增删行. 新 DataInput.registry_extracts, ACC-04 的 reads 加它.
9. 补交请求名改为 "ASIC 摘录" (en "ASIC extract").
10. "有摘录" 按文件类型算. ACN 对不上时 company_registered 不通过; 抽取没成时两项待人工确认.

补充裁定:

- (1) 主图拓扑变了: graph.py 模块说明, 接口文档第 3 节与 Demo需求文档第 4.1 节同步改; 拓扑守卫按新拓扑改, 不删; 核对旧检查点能接着跑 (至少停在 ACC-01 闸门的旧检查点能 rerun), 结果写在本材料里. 见 "讲解" 的 "旧检查点".
- (2) 接受两次 ABN 查询 (p0_inputs 一次, ACC-04 一次), 两条留痕都要有, 测试断言次数.
- (3) 测试按 "写测试": 新客户的等待与继续只跑一次全流程; DOC-REGISTRY 提示词按关键词断言.
- 过期 (开工中提出, 协调者取 A): reads 保留 registry_extracts. 本材料写明限制与绕法 (见偏离第 3 条), 协调者另记后续项. 改摘录照样出新版本, 写留痕, 记数据变动.

1. AsicExtract 结构扩了: 需求原文写 "按 R129 的 AsicExtract 结构", 又在范围里列了 ABN 与注册地址, R129 的结构没有这两项. 按裁定 7 加了可空的 abn 与 registered_address. 另加 `document_id` 与 `evidence`, 让 ACC-04 的指针指向上传的文件, 页码取抽取时的指针. 都可空或缺省为空, 数据集的 mock 不填, 补造数据不改.
2. 运行中的演示 (mock 模式) 的摘录抽取, 已按协调者裁定 (a) 处理 (fix 提交):
   - 原稿: DOC-REGISTRY 的固定输出只放在上传处理的公共目录 (tests/fixtures/llm_variants/upload), 没有同步进运行副本. 新客户读 Numbat 的运行副本 data/demo/llm, 在 LLM_MODE=mock 的应用里上传摘录抽不出, 文件转 needs_manual (extract), ACC-04 的公司两项待人工确认.
